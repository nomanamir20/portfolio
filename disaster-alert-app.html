AI Disaster Alert App

A Flutter-based disaster early warning mobile application designed to support emergency response through alerts, incident reporting, shelter information, maps, and notifications.

Project Overview

The AI Disaster Alert App is a mobile application developed using Flutter. The project focuses on improving emergency response by giving users access to disaster alerts, incident reporting, shelter information, and location-based services.

The application combines mobile development with external services and APIs to provide useful information to users during emergency situations.

View Source Code

Problem

Many people may not receive disaster warnings quickly enough, making emergency response more difficult. Users may also need information about incidents, nearby shelters, and emergency situations in one accessible mobile application.

Solution

The application provides a mobile interface through which users can receive emergency alerts, report incidents, view interactive maps, find shelter locations, and receive important notifications.

Technology Stack

Flutter Dart Firebase Google Maps API REST APIs

Key Features

🚨 Emergency Alerts

Provides users with important disaster and emergency alerts.

📍 Incident Reporting

Allows users to report disaster-related incidents.

🗺️ Interactive Maps

Uses map services to provide location-based information.

🏠 Shelter Locations

Provides information about available shelter locations.

🔔 Push Notifications

Supports notifications for important emergency information.
