AI Disaster Alert App

An AI-powered disaster early warning mobile application developed using Flutter. The project aims to improve emergency response by providing disaster alerts, incident reporting, shelter information, and live notifications.

Problem

Many people do not receive disaster warnings quickly enough, making emergency response difficult.

Solution

The application delivers emergency alerts, allows users to report incidents, locate nearby shelters, and receive important notifications in real time.

Technologies Used

  • Flutter
  • Firebase
  • Google Maps API
  • REST APIs
  • Dart

Key Features

  • Emergency Alerts
  • Incident Reporting
  • Interactive Maps
  • Shelter Locations
  • Push Notifications

What I Learned

Through this project I improved my Flutter development skills, API integration, Firebase usage, state management, and mobile application architecture.
