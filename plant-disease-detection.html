Plant Disease Detection System

This project is an AI-powered web application that detects plant diseases from leaf images using machine learning. The system helps farmers identify diseases quickly and supports better crop management.

Problem

Farmers often struggle to identify crop diseases early, which can reduce yield and increase losses.

Solution

The application uses a trained deep learning model to classify plant diseases from uploaded leaf images and provide instant predictions.

Technologies Used

  • Python
  • TensorFlow / Keras
  • Flask
  • PHP
  • MySQL
  • Bootstrap

Key Features

  • Image upload
  • Disease prediction
  • Confidence score
  • User-friendly web interface
  • Fast prediction results

What I Learned

This project improved my understanding of machine learning workflows, image classification, TensorFlow model deployment, Flask APIs, and integrating AI models into web applications.
